# 03: Should we use WTForms or make forms manually with with html

## Meta

Status
: Work in progress - **Decided** - Obsolete

Updated
: 12-June-2026

## Problem Statement

For our project we need a form for three parts of our web application. The register page, the login and the create meal page.
We were thinking if adding another Flask extension Flask-WTF is neccesary.

## Decision

We decided to implement Flask-WTF extension for our project to keep an overview on our forms.
Additionally WTForms works well with SQLAlchemy. The resources Mr. Eck provided convinced us that using the WTForms is the right decision for our project.

*Decision was taken by:* github.com/juliadhwr

## Regarded options

We regarded two options:

+ Continue without the Extension
+ With WTForms

| Criterion | Without WTForms | With WTForms|
| --- | --- | --- |
| **Efficiency** | ❌ each form | ✔️ Forms are defined as Python classes |
| **Convinience** | ❌ Validators would be written manually for each field which can lead to mistakes | ✔️ Validators are included |
| **Data security** | ❌ Would have costed extra efforts to provide form security | ✔️ Automatically includes CSRF and chosen Validators offer proper secure forms |
| **Compatibility** | ❌ No difference | ✔️ Flask supports the integration of the Extension, can be easily connected to SQL Alchemy |

❔
