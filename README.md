# Kochb-rse
Wir möchten eine Kochbörse auf die Beine Stellen. Mit dem Motto "Von Studenten für Studenten" können sich Studenten austauschen, um füreinander zu kochen, Ressourcen zu sparen und neue Leute kennenzulernen. Studenten können sich anmelden, Wochenpläne erstellen und bei "Überschuss" veröffentlichen, um einen Teil Ihrer Kreation zu verkaufen.
